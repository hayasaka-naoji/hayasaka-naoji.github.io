写于乡下

好几天没写博客了。倒也不是没东西写，就是每天过得都差不多——在乡下待着，白天吹风扇，晚上看星星，日子慢得像凝固了一样。假期快结束了，30号回宁波，然后收拾收拾就该开学了。

晚上翻手机，看到之前列的这学期计划。写的时候挺认真的，现在再看，倒也没什么要改的。索性直接贴在这儿，方便以后翻看。计划这种东西，写的时候觉得是给自己打气，过几个月回头看，能做成一半就算不错了。但也总比什么都没写好。

二、学期阶段划分

阶段一：9 月（第 1~4 周）——启动与适应

  • 固定作息与运动习惯，开始控制饮食，晚饭后跑步。
  • 技术学习以 Python 入门 + STM32 环境搭建 为主。
  • 英语开始背四级单词，每天 30~50 个。
  • 日语每天 10~15 分钟，学习五十音或简单对话。
  • 了解边缘 AI 基本概念，只看科普视频或文章。

阶段二：10 月11 月（第 514 周）——全力推进

  • 技术主线进入 STM32 系统学习 + 小项目，Python 继续深入（numpy、pandas）。
  • C 语言通过 STM32 编程持续使用，不再单独花时间。
  • 英语开始做四级真题阅读和听力，每周 2~3 次。
  • 边缘 AI 利用碎片时间关注动态，可尝试了解 TensorFlow Lite 等。
  • 减肥保持每周减 1~1.5 斤。
  • Office 每周 1~2 次专项练习。

阶段三：12 月1 月初（第 1518 周）——收尾与调整

  • 期末课程任务增多，技术学习时间适当压缩，但仍保证每周至少 4~6 小时。
  • 英语保持背单词和听力，不中断。
  • 减肥若未达标，增加运动量或更严格控制饮食。
  • 总结 STM32 项目，整理成笔记或小文档。
  • Python 可尝试与 STM32 结合，如写串口数据读取脚本。
  • 日语保持兴趣，不给自己压力。

  • 周末上午和下午各 3 小时学习，留出休息时间，避免过度疲劳。

四、各模块具体执行方案

1. 减肥计划（高优先级）

  • 目标：170 斤 → 150 斤，减重 20 斤，平均每月 5 斤。
  • 运动：每周至少 5 次，晚饭后操场慢跑/快走 30~40 分钟。周末可增加一次力量训练或较长时间有氧。膝盖不适时改为快走或跳绳。
  • 饮食：早餐正常，午餐八分饱，晚餐少主食，多蔬菜蛋白质。戒奶茶、碳酸饮料、夜宵。跑步后只喝水或吃少量水果。
  • 记录：每周一早上空腹称重一次，记录趋势，连续两周无下降则调整饮食或增加运动。

2. 英语四级备考（高优先级）

  • 目标：2027 年 6 月低分飘过，本学期重点打基础。
  • 每日任务：背单词 APP（百词斩/墨墨）每天 40~60 个。听力每周 3 次，每次 20 分钟。阅读每周 2 篇真题阅读。
  • 时间安排：碎片时间背单词，晚上学习前后安排听力/阅读。
  • 注意：不急于做整套题，先积累词汇和语感。

3. STM32 系统学习（高优先级）

  • 目标：系统掌握常用外设，独立完成 1~2 个小项目。
  • 硬件准备：STM32F103C8T6 最小系统板或 F407 开发板 + ST-Link。
  • 学习路线：环境搭建 → GPIO → 中断/定时器 → 串口 → PWM → ADC → I2C/SPI → 项目实战
  • 时间安排：周三下午或周六上午整块时间 2~3 小时，动手写代码。

4. Python 学习（高优先级）

  • 目标：掌握基础语法，能用 Python 处理数据、写脚本。
  • 阶段：基础语法（14周）→ numpy/pandas/matplotlib（510周）→ opencv/requests 小脚本（11~14周）→ 与STM32结合。
  • 资料：B 站黑马程序员/小甲鱼，菜鸟教程、廖雪峰。

5~9. 其他（C语言保持、边缘AI碎片化了解、SQL/Java基础、Office提升、日语兴趣）

按原计划执行，不做额外展开。

六、注意事项

  1. 主次分明：核心是 减肥 + STM32 + Python + 英语四级，不要贪多。
  2. 灵活调整：学生工作或临时任务繁忙时，可减少学习量，但运动尽量保持。
  3. 定期复盘：每两周花 30 分钟回顾执行情况。
  4. 保证睡眠：坚持 23:00 前睡觉。
  5. 健康减肥：不节食过度。
